## ⭐ The finding: A BUILD THAT DOES NOT RUN ITS OWN PREMISE HAS SKIPPED A STEP

**Three artifacts measured their own premise on 2026-09-05/06. All three found it wrong.** This is
a claim about method, not about care: every one of these builds was competent, and in each case the
code read correctly and behaved otherwise.

| the premise, as written | what running it showed |
| --- | --- |
| #238: a round trip proves the committed table is what its generator emits | **It passed for all three pairs with two rows deleted from the real table.** The round trip feeds the file's own data back in, so it is vacuously true for that data. A single check would have closed the issue while leaving the defect it names. |
| #225: pin the shell, and the test stops inheriting its meaning | **The guard added to prove the fix was itself ambient**, green wherever the environment happened to supply what it checked for, so on CI it could never fail. The defect reappeared inside its own fix. |
| #233: delete the granting path and the instrument can only refuse | **One granting path remained and it granted on a substring.** A verdict naming a different commit, and a findings comment carrying a clean phrase, both printed READY. |

⛔ **None of the three was catchable by reading.** Each was found by executing the premise and
watching what happened, and in two of the three the finder was the build or the review seat rather
than the conductor.

**Why this belongs beside the fix-round question.** The existing rule asks whether a fix exhibits
the class of defect it fixes. This is the same question asked one step earlier, of the build rather
than the repair: **the premise a build rests on is itself a claim, and a claim that has not been
run has not been checked.** Two of the three above are literally that rule applying to a fix, and
the third is it applying to a design.

⚠️ **The cheap wrong reading is "test more carefully".** The right reading is narrower: **when a
build's plan states a property as the reason the change works, run that property before building on
it.** #238's build did exactly this, unprompted, and that is why it is in this table with an answer
rather than in a later review round as a defect.
